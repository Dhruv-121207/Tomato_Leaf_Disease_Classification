# Tomato Leaf Disease Classification

**AI-powered tomato leaf disease classification using PyTorch, ResNet18 transfer learning, FastAPI, and a custom web interface.**

Tomato Leaf Disease Classification is an end-to-end deep learning project built for **multi-class tomato leaf disease detection**. The project began with a **custom CNN baseline model built from scratch**, followed by a transition to **ResNet18 transfer learning**, which significantly improved performance.

The final model classifies tomato leaf images into **ten categories**, including multiple disease classes and healthy leaves.

The trained model is integrated with a **FastAPI backend** and deployed through a simple web interface where users can upload a tomato leaf image and receive the predicted class along with the model's confidence score.

## Model Development

### CNN Baseline

A custom CNN model was built and trained from scratch as the initial benchmark.

| Model | Validation Accuracy | Test Accuracy |
| --- | ---: | ---: |
| Custom CNN | **91.0454%** | **91.8019%** |

The baseline model provided a strong starting point, but transfer learning was used to improve generalization and overall performance.

### Final Model – ResNet18 Transfer Learning

A pretrained ResNet18 model was fine-tuned for tomato leaf disease classification.

| Model | Validation Accuracy | Test Accuracy |
| --- | ---: | ---: |
| ResNet18 | **98.6672%** | **98.3770%** |

**Input Size:** 128 × 128

The transition from the custom CNN baseline to **ResNet18 transfer learning** resulted in a substantial improvement in both validation and test accuracy.

## Supported Classes

The model predicts one of the following ten tomato leaf categories:

- Tomato Bacterial Spot
- Tomato Early Blight
- Tomato Late Blight
- Tomato Leaf Mold
- Tomato Septoria Leaf Spot
- Tomato Spider Mites / Two-Spotted Spider Mite
- Tomato Target Spot
- Tomato Yellow Leaf Curl Virus
- Tomato Mosaic Virus
- Tomato Healthy

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Dhruv-121207/Tomato_Leaf_Disease_Classification.git
cd Tomato_Leaf_Disease_Classification
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

### Windows

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
uvicorn app:app --reload
```

Then open:

```text
http://127.0.0.1:8000
```

## Limitations

- The model is trained only on tomato leaf images
- It does not support disease detection for other plant species
- Predictions may be affected by image quality, lighting conditions, and background noise
- High-confidence predictions can still be incorrect
